## 🚀 Featured Project — [CareerCoach AI](https://careercoach-ai-omega.vercel.app/)

**A production SaaS that helps job seekers improve their resumes with AI feedback grounded in their actual document.**

<table>
<tr>
<td width="50%">

**Stack**
- **Frontend:** Next.js 16, TypeScript, Tailwind
- **AI:** Claude 3.5 Sonnet, custom RAG pipeline
- **Vector DB:** Pinecone (semantic retrieval over uploaded PDFs)
- **Auth & Payments:** Clerk, Stripe
- **Infra:** Vercel

</td>
<td width="50%">

**What it actually does**
- Ingests a user's resume PDF and embeds it for retrieval
- RAG layer grounds every Claude response in the user's own document — preventing hallucinated advice
- Streams structured feedback (clarity, ATS-fit, weak bullets) back to the UI
- Paywall + auth flow handled end-to-end

</td>
</tr>
</table>

**Why it matters:** most "AI resume tools" generate generic advice. The RAG grounding is what makes the feedback actually about *your* resume — and shipping that pipeline reliably is the interesting engineering problem.

🔗 **[Try it live →](https://careercoach-ai-omega.vercel.app/)**
